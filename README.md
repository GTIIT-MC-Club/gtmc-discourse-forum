# gtmc-discourse-forum

GTMC 论坛的部署配置和设计稿。

- `infra/`：部署脚本、Discourse 容器配置、初始化脚本和论坛内容，见 [infra/README.md](infra/README.md)
- `design/`：Logo、图标和界面设计稿

插件和主题在各自的仓库里（Discourse 要求仓库根目录就是插件或主题）：
[gtmc-forum-plugin](https://github.com/GTIIT-MC-Club/gtmc-forum-plugin)、
[gtmc-forum-theme](https://github.com/GTIIT-MC-Club/gtmc-forum-theme)。
