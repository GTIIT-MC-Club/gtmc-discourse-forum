# 后台配置：脚本做了什么，还剩哪些要手动

站点设置、主题导入与配色、侧边栏、徽章、引导机器人都由 `infra/discourse/` 下的脚本完成，可重复执行。
在后台改了脚本管着的东西，下次重跑会被改回来；要改就改脚本（或脚本读的文件）。换届时交给下一任照着做。

**现状**：这些脚本在本地开发站（Discourse main，`bin/rails runner`）上每个都连跑过两次，
**尚未在社团真机的容器里执行过**。容器里的用法写在每个脚本的文件头。真机做过之后把这一行改成实际操作过的版本号。

---

## 一、执行顺序

| 顺序 | 脚本 | 做什么 |
|---|---|---|
| 1 | `site_settings.rb` | 站点设置、版块和发帖模板、信任等级门槛、自定义状态、引导机器人的欢迎私信开关 |
| 2 | `import_theme.rb <theme 目录>` | 打包并导入 GTMC 主题、设为默认主题、浅色配色 GTMC Light 和深色配色 GTMC Dark（两套都允许用户自选） |
| 3 | `sidebar.rb` | 版块顺序和图标、默认侧边栏、「社区」区链接、页脚的站内链接 |
| 4 | `badges.rb` | 「社团成就」分组和四枚社团徽章，核心自带徽章的中文改名 |
| 5 | `narrative_bot.rb` | 引导机器人改名、头像、简介和教程台词 |

后一个脚本依赖前面的结果，缺了会报错退出，不会只做一半。
容器里怎么传文件：`import_theme.rb` 要把 `theme/` 目录复制进容器并把容器内路径作为参数，
`narrative_bot.rb` 要把整个 `infra/` 复制进容器，其余脚本单个文件即可，具体命令见各文件头。

需要回来重跑的时候：

- **发了「新人指南」置顶帖之后**：重跑 `sidebar.rb`（页脚的「新人指南」才会从版块改成指向帖子），
  再重跑 `narrative_bot.rb`（教程结尾的链接同理）。
- **改了 `theme/` 之后**：重跑 `import_theme.rb`，每次都会重新导入一遍，结果相同。
- **版块改名（「红石与技术」→「技术开发」、「模组与资源」→「资源分享」）和新增「新人指南」版块之后**：
  已经跑过旧脚本的站按 1→5 全部重跑一遍。`site_settings.rb` 按 `previous_names` 原地改名，帖子和版块地址不变；
  `badges.rb` 按版块名统计，不重跑的话「红石工程师」查不到帖子。原来发在「公告」的「新人指南」置顶帖，
  在帖子标题旁把版块改成「新人指南」，再重跑 `sidebar.rb` 和 `narrative_bot.rb`。
- **General 版块没被删掉时**：`sidebar.rb` 只删除除了核心欢迎帖以外没有帖子的 General，
  有人在里面发过帖就保留并打印 `kept category General`。把那些帖子移到合适的版块后重跑。

**Logo 要手动上传一次**（脚本不管）：后台 → 设置 → 品牌 → Logo，上传仓库里的 `design/brand/gtmc-logo-3x.png`。
主题给 Logo 开了像素化缩放，边缘保持方块。小 Logo（`logo_small`，页头收起时显示的方形图）还没定稿，暂时留空，用核心默认。

「老玩家俱乐部」在默认侧边栏里，但它只对信任等级 2 及以上可见：核心按权限过滤，
新人的侧边栏里看不到它，升到 2 级后自动出现，不会点进去吃「无权访问」。

## 二、徽章

目标：让「发了好帖」「帮了别人」这件事在论坛上留下痕迹。徽章由 `badges.rb` 创建，名称、说明、图标、授予条件都写在脚本里。

| 徽章 | 等级 | 图标 | 授予方式 | 授予条件 |
|---|---|---|---|---|
| 初来乍到 | 铜 | 核心默认 | 自动（核心的信任等级 1 徽章，脚本只改中文名和说明） | 升到信任等级 1 |
| 建筑师 | 银 | 砖墙 | 自动，每天核对一次 | 在「建筑展示」发的作品帖里有上传的图片，且这篇帖子收到至少 3 个赞 |
| 红石工程师 | 银 | 齿轮 | 自动，每天核对一次 | 在「技术开发」发了装置帖，保留模板里的「目标」「版本与依赖」「现状」三个小标题、至少收到 1 个赞，并且在这个版块回复过别人发的话题 |
| 活动常客 | 铜 | 蛋糕 | 自动，每天核对一次 | 在「活动」版块里别人发的 3 个以上不同的话题下回过帖（即报名） |
| 引路人 | 金 | 指南针 | **手工授予** | 带会了至少一位完全的新手：对方的第一篇帖子或第一次进服是你带的 |

自动授予的几条是对原设计的**近似**，管理员要知道它看不到什么：

- 建筑师：看不出作品是不是原创。搬运的帖子被删后，下一次每日核对会收回徽章。
- 红石工程师：只检查模板小标题还在、有人点赞、回复过别人，看不出装置能不能复现、回复算不算答到点上。
- 活动常客：「参加」只能近似成「报名」，核心不记录谁真的到场。
- 查询只统计公开版块里未删除的帖子（读核心的 `badge_posts` 视图），私信和受限版块不算。

新徽章最迟一天后才会出现（核心每天跑一次）。想立刻看到：在 `rails runner` 里执行
`BadgeGranter.backfill(Badge.find_by(name: "建筑师"))`。

**自动授予的徽章不能靠删除用户的徽章来收回**：只要条件还满足，下一次每日核对又会授予。要收回，处理造成条件满足的帖子（删帖、移出版块）。

**查询在后台看不到**：脚本不需要隐藏设置 `enable_badge_sql`，核心定时授予时也不检查它。
它只管后台徽章编辑页的「查询」输入框和预览，打开后任何管理员都能在页面上写任意 SQL，权限太大，所以保持关闭。
要看或改查询，读改 `badges.rb`。

**手工授予「引路人」**：后台 → 徽章 → 引路人 → 授予 → 填用户名 → 确认。
徽章稀有一点才有意义，别为了省事给所有活跃用户都点一遍。

核心自带徽章只改了中文界面里显示的名称和说明（翻译覆盖），徽章本身不动：
信任等级 1 → 初来乍到，首个赞 → 点亮火把，首次链接 → 搭好第一座桥，首个表情 → 气氛组，
首次引用 → 引经据典，首次提及 → 喊人组队，首次分享 → 传送门。英文界面的用户仍看到英文原名。

## 三、引导机器人

核心自带的 discourse-narrative-bot 插件里的机器人原名 discobot，现在叫**小火把**（用户名 `gtmc_torch`），
头像是仓库里原创的像素火把（`infra/content/narrative-bot/avatar.png`，源文件和生成脚本在同一目录）。
新用户注册后自动收到教程私信，教完基本操作，结尾引导去「白名单与申诉」申请白名单、读「新人指南」。

- 台词在 `infra/content/narrative-bot/zh_CN.yml`，改了重跑 `narrative_bot.rb`。文件头写了哪些文字受插件代码约束、不能随便改。
- 教程的流程（步骤顺序、每步怎么判定通过）由插件代码决定，改台词改不了它。
- 结业证书的图片模板没动，证书上机器人的署名随用户名变成 `gtmc_torch`。
- 只覆盖了中文台词；界面语言是英文的用户看到插件自带的英文。
- 已注册的用户不会补发教程；想再走一遍的话，给机器人发私信，它会回复怎么开始。
- 想换名字或头像：改 `narrative_bot.rb` 开头的常量或替换 `avatar.txt` 后运行 `ruby infra/content/narrative-bot/build_avatar.rb`，再重跑脚本。

## 四、设置完之后的自查

- [ ] 未登录窗口里左侧栏的版块按「公告、新人指南、活动、建筑展示、技术开发、资源分享、白名单与申诉、水吧」排列，每个前面是像素图标。
- [ ] 新注册的测试账号（TL0）点「白名单与申诉」能看到发帖模板，标题框有灰字提示。
- [ ] 测试账号看不到「老玩家俱乐部」。
- [ ] 「欢迎与社区规则」置顶帖发在「公告」，「新人指南」置顶帖发在「新人指南」版块，都全局置顶；发完后重跑了 `sidebar.rb` 和 `narrative_bot.rb`，页脚的「新人指南」点开是那篇帖子。
- [ ] 页脚（任意页面拉到底）有社团名、三到四个链接和商标声明；「新人指南」「白名单与申诉」点得开；填了 `discord_invite_url` 之后多出「加入 Discord」。
- [ ] 页头左上角是社团的像素 Logo，放大浏览器也是清晰的方块边缘，不是糊的。
- [ ] 把系统切到深色模式再打开论坛，是 GTMC Dark；浅色模式是 GTMC Light。用户的「偏好设置 → 界面」里能选这两套配色。
- [ ] 徽章页 `/badges` 能打开，最前面的「社团成就」分组里有建筑师、红石工程师、活动常客、引路人，图标是像素图标。
- [ ] 用户菜单（点头像 → 个人标签）里有「设置自定义状态」。
- [ ] 新注册一个测试账号，收件箱里有「欢迎来到 GTMC！我是小火把」的私信，发信人头像是火把。
