---
title: 启动器是什么
---

**Minecraft 本体**是游戏本身：一堆游戏文件，加上运行它要用的 Java。
**启动器**是帮你管理本体的程序：下载指定版本、登录账号、安装模组，最后点「启动」把游戏打开。

打个比方：本体是游戏卡带，启动器是游戏机。同一台游戏机可以放好几张卡带（多个版本），
换一台游戏机（换启动器）也还能玩同一张卡带。

## 为什么要关心启动器

- **版本**：社团的几个服版本不一样，启动器让你同时装好几个版本，进哪个服开哪个。
- **模组**：模组服要先装模组加载器，好的启动器一键装好，不用自己折腾文件。
- **账号**：启动器决定你用什么名字进服。这个名字就是你的游戏名，绑定论坛账号、申请白名单都用它。

## 常见的几个

| 启动器 | 系统 | 适合谁 |
|---|---|---|
| 官方启动器 | Windows / macOS / Linux | 买了正版、只玩原版 |
| HMCL | Windows / macOS / Linux | 大多数同学，中文界面，装模组方便 |
| PCL2 | 只有 Windows | Windows 用户，中文界面，功能多 |
| Prism Launcher | Windows / macOS / Linux | 想管理很多个整合包 |

拿不准就用 **HMCL**：三个系统都能用，界面是中文，会自动下载需要的 Java。

只从官网或项目的 GitHub 页面下载启动器。网盘里的「整合版」「免安装版」可能被改过，装了等于把电脑交给别人。

## 账号

社团的服务器是离线模式：正版账号能进，启动器里新建的离线账号也能进。

离线账号要注意：

- 名字的**大小写**要和白名单上的完全一样，`Steve` 和 `steve` 在服务器看来是两个人。
- 换电脑、换启动器时用同一个名字，否则背包和领地都对不上。
