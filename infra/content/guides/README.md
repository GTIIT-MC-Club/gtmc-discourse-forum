# 新手教程：怎么写、怎么发到论坛

这个目录里除了本文件，每个 `.md` 文件就是论坛「新人指南」版块里的一个话题。
**仓库是唯一的源**：论坛上的首帖由 `infra/discourse/guides.rb` 从这里同步，并且被锁定，
普通用户（包括发帖人）不能编辑；管理人员在论坛上改了，下次同步也会被仓库的版本覆盖。
要改教程，改这里的文件，合并后重新部署。读者的补充和纠错在帖子下面回复，帖子末尾有回到这里的「在 GitHub 上修改」链接。

## 文件格式

每个文件以 front matter 开头，`title` 就是论坛话题的标题。正文里不要再写一级标题（`# ...`），论坛会把话题标题显示在上面：

```markdown
---
title: 启动器是什么
---

**Minecraft 本体**是游戏本身……
```

- 文件名和子目录名只用小写英文字母、数字和连字符，例如 `servers/fabric.md`。
  文件路径决定教程的固定网址：`launcher.md` → `/wiki/launcher`，`servers/fabric.md` → `/wiki/servers/fabric`。
  **发布之后不要改文件名**：同步脚本按路径找到对应的话题，改了名会当成新教程再发一篇。
- 标题不能和别的教程重名。
- 本文件（`README.md`，任何一层目录里的都一样）给维护者看，不会发到论坛。

## 链接其他教程

链接写成相对路径，在 GitHub 上能直接点，同步时会换成论坛话题的地址：

```markdown
装之前最好先读一下 [启动器是什么](./launcher.md)。
```

- 链接后面的 `#锚点` 原样接在话题地址后面。论坛给小标题生成的锚点和 GitHub 的不一定相同，跳不到那一节时只会停在话题开头。

- 相对链接只能指向另一篇教程的 `.md` 文件，路径相对于当前文件所在的目录（子目录里用 `../launcher.md`）。
  指向不存在的文件、图片或其他相对路径时，同步脚本会列出所有出错的链接并退出，论坛上什么都不会改。
- 站外地址（`https://...`）和站内的绝对路径（`/c/...`）原样保留。
- 代码块和行内代码里的链接不会被检查或改写。

## 为什么一个概念一篇

「启动器是什么」会被「安装 Minecraft」「装模组」等好几篇用到。只在一处写，其他地方链过去，
改的时候改一处就够了。复制粘贴的段落迟早会互相矛盾。

论坛上被链接的那一篇底下会自动列出「谁链接了我」，能反查哪些教程依赖它，改之前先看一眼。

## 加一篇新教程

1. 在这个目录（或子目录）新建 `.md` 文件，写好 front matter 和正文。
2. 在 `index.md`（目录帖，在版块内置顶）里加上它的链接。
3. 提 PR，合并后在论坛机器上执行 `sudo infra/deploy-discourse.sh`，或单独执行同步脚本
   （用法见 `infra/discourse/guides.rb` 文件头）。

同步脚本可以重复执行，没改过的教程只打印 `is up to date`。删掉一个文件不会删掉论坛上的话题，
脚本只打印一条警告，要删的话由管理员在论坛上处理。

## 论坛上已有的同名话题

同步时如果某个文件还没有对应的话题，脚本先在「新人指南」版块里找标题完全相同的话题接管（打印 `adopted`），
找不到才新发一篇。之前手工发的「启动器是什么」「版本号和模组加载器」就是这样接管的，原来的回复都保留。
接管时首帖会被覆盖成仓库的版本，脚本会打印最后一次在论坛上编辑它的人，方便确认没有丢掉要留下的改动。
