# 新手教程：怎么发到论坛

这个目录里每个 `.md` 文件是论坛上的一个话题，首帖设成 wiki，大家一起改。
目录帖（`index.md`）置顶，列出所有教程的链接。

## 为什么一个概念一篇

「启动器是什么」会被「安装 Minecraft」「装模组」等好几篇用到。只在一处写，其他地方链过去，
改的时候改一处就够了。Discourse 不能把一篇的内容嵌进另一篇，复制粘贴的段落迟早会互相矛盾。

被链接的那一篇底下会自动列出「谁链接了我」，能反查哪些教程依赖它，改之前先看一眼。

## 发帖顺序

文件之间的链接写成相对路径（`./launcher.md`），在 GitHub 上能直接点。
论坛话题的地址发完才知道，所以要**先发被引用的，再发引用别人的**，发每一篇前把相对路径换成论坛地址：

1. `launcher.md`：启动器是什么（不引用其他教程）
2. `versions-and-loaders.md`：版本号和模组加载器（引用 1）
3. `install-minecraft.md`：下载并安装 Minecraft（引用 1、2）
4. `index.md`：教程目录（引用全部），发完置顶

每篇发完：帖子右下角「…」→ 扳手 → 「设为 wiki」。

## 发到哪个版块

「新人指南」版块（`infra/discourse/site_settings.rb` 创建）。目录帖和原来的「新人指南」置顶帖都在这个版块置顶。

## 论坛上的改动怎么回到这里

wiki 帖发出去以后以论坛上的版本为准，这里的文件只是初稿。
有大改动时把论坛上的正文复制回来提交一次，换届的时候不会丢。
