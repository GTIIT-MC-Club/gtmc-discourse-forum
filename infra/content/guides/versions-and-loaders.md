---
title: 版本号和模组加载器
---

进服失败最常见的原因是版本不对。这一篇讲清楚「版本」到底指什么。

## 游戏版本

`1.20.1`、`1.21.1` 这样的数字是 Minecraft 本体的版本。**客户端和服务器的版本要一模一样**，
差一位小版本号也可能进不去。

每个服的版本写在论坛首页的服务器状态里，进服之前先看一眼。

## Java 版本

Minecraft Java 版要用 Java 运行，不同游戏版本要的 Java 不同：

| 游戏版本 | 需要的 Java |
|---|---|
| 1.20.5 及以后 | Java 21 |
| 1.18 到 1.20.4 | Java 17 |
| 1.16.5 及以前 | Java 8 |

官方启动器和 HMCL 会自动选好 Java，一般不用管。
看到「Java 版本不对」之类的报错，到启动器的版本设置里把 Java 改成表里那一个。

## 模组加载器

原版游戏不能直接装模组，要先装一个**模组加载器**，模组才能被读进去。常见的三个：

| 加载器 | 特点 |
|---|---|
| Fabric | 轻量、更新快，优化类和小工具模组多 |
| Forge | 历史最久，老版本的大型模组多 |
| NeoForge | 从 Forge 分出来的，1.20.2 以后很多大型模组改用它 |

三条规则：

1. **服务器用哪个加载器，你就装哪个。** Fabric 的模组不能装在 Forge 上，反过来也不行。
2. **模组要和游戏版本对上。** 下载模组时选和服务器一样的游戏版本。
3. **服务器装了的「必需」模组你也要装。** 缺了会在进服时提示缺哪些。

加载器用启动器装最省事，见 [启动器是什么](./launcher.md)。
