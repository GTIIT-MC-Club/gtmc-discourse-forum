# 下载并安装 Minecraft

从零开始到能进社团的服务器，大约 20 分钟，大部分时间在等下载。

装之前最好先读一下 [启动器是什么](./launcher.md)，知道本体和启动器的关系，下面的步骤会好懂很多。

## 1. 装启动器

拿不准用哪个就装 HMCL，到官网下载对应系统的版本。其他选择见 [启动器是什么](./launcher.md)。

## 2. 添加账号

- 有正版：选「微软账号」登录。
- 没有正版：选「离线账号」，填你的游戏名。

游戏名之后要用来申请白名单、绑定论坛账号，起一个以后不想改的。只用英文字母、数字和下划线最稳妥。

## 3. 下载游戏版本

1. 打开论坛首页，在服务器状态里看你想进的那个服是什么版本。
   是不是模组服、用哪个加载器，看那个服的介绍帖或问管理员。
   看不懂这两项就读 [版本号和模组加载器](./versions-and-loaders.md)。
2. 在启动器的「下载」里选同一个游戏版本。
3. 如果是模组服，下载时勾上对应的加载器（Fabric / Forge / NeoForge）。

## 4. 启动一次

先不进服，单人模式建一个世界，确认能正常打开。打不开的话截图启动器的报错，到「技术开发」发帖问。

## 5. 进服

1. 到「白名单与申诉」按模板申请白名单，等管理员通过。
2. 在论坛首页的服务器状态里点一下服务器地址，复制下来。
3. 游戏里「多人游戏」→「添加服务器」→ 粘贴地址 → 加入。

## 进不去？

| 提示 | 一般是因为 |
|---|---|
| 版本不对 / Outdated client | 游戏版本和服务器不同，回第 3 步 |
| 缺少模组 / Mod rejections | 模组服缺模组或加载器不对，见 [版本号和模组加载器](./versions-and-loaders.md) |
| 不在白名单上 | 申请还没通过，或者游戏名大小写和申请时不一样 |
| 连接超时 | 服务器可能没开，看论坛首页它是不是在线 |
